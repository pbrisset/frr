# Provenance and reproducibility

The audit started on `dev/guna-experiments`, commit `fd70931112f3f1ea5899713cc14dbe10e7982442`, one commit ahead of `origin/dev/guna-experiments`. The earlier `week5-ip-relearning` directory already had staged additions; they were preserved. Its 1,108 hashes were rechecked without mismatch. The new audit is untracked. The temporary topotest copies used to run these experiments were removed after teardown.

The existing privileged `frr-dev` container ran kernel `6.8.0-117-generic #117-Ubuntu SMP PREEMPT_DYNAMIC` on aarch64. Its Zebra identifies as `10.8.0-dev-my-manual-build`; `/usr/lib/frr/zebra` SHA-256 is `d70f102f9171f006740c63b97f6e918d58aa8f197bd144dfa4dfda12539ddd5e` and `/usr/lib/frr/bgpd` SHA-256 is `cb80f72969655250706292cada52e5c27db9e6f68ad6d1d7b81f47d232c056a0`. Binary hashes do not establish exact source or build flags. Repository source hashes are in `source-sha256.csv`.

Twenty matched trials all returned `1 passed` from fresh sequential pytest invocations; `raw-immediate-01` passed in 46.54 s, but its standalone pytest stdout was not saved. The additional access-port validation passed in 40.26 s; its standalone stdout was not saved. The other 19 matched pytest logs are retained. Every raw directory includes the original harness manifest and a supplemental `causal-manifest.json`; condition for the no-announcement runs is recorded from invocation/directory because the original manifest filters out `CAUSAL_CASE` and its worker emits no lines. All five leaf DAD configuration outputs in each run report enabled, 5 moves in 180 s.

`capture-counters.csv` indexes all 232 capture statistics logs. `clock-calibration.csv` lists worker realtime/monotonic call pairs; it is not a rigorous cross-clock error bound. `SHA256SUMS` covers all new package files except itself. Each raw `timeline.html` separates monotonic and realtime observations. Realtime packet and netlink observations were taken in the shared Linux time namespace; their observation delays and timestamp errors are not calibrated.
